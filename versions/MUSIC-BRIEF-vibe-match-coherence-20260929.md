## Distinct worlds per mood
Each live vibe should feel like a **different music-video set**, not a recolor of neon hub:
| Mood | World identity (examples) |
|------|---------------------------|
| Peaceful | Nature / soft highway dusk / dream clouds — heal light |
| Warm groove | Night street / warm rain city — body pocket, not war |
| Tense | Storm edge / cold ruins / industrial soft — braced |
| Aggressive/chaos | Fracture / storm / warzone / red void — ash + kick punch |
| Scary | Isolation void / staircase / sparse dread — not party chaos |
| Spoken | Intimate room / soft void — lyric-as-world |

If two moods share a pack family, **silhouette + lighting + cast action** must still read different (meadow ≠ storm edge with trees).

## One thread, earned shifts
- **Open one movie.** Verse plants place + cast/motif; chorus = **same world bigger** (scale, trim, light) — not a random teleport.
- **Earn the jump.** Peaceful→aggressive only when ear earns it (build / harsh+kick storm / section gate). No bar-1 warzone on a soft intro; no meadow snap mid-blast.
- **Motif memory.** Crosshair / figure / color accent returns after a chaos peak so the head-movie feels continuous (This Is America chapter grammar; psych anticipation→peak→soothe).
- **Anti-coherence:** roulette packs each phrase; neon hub as forever default; mood flip without energy/vibe change; soft pastoral bleeding into metal peak.

## Slice
Scene owns thread + when to shift; Worlds supply distinct mood packs; Visual keeps lighting/motion in-family across the morph.
