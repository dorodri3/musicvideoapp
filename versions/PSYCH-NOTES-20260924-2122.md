## Mechanisms → Light Show verbs

### 1) Arousal & peak pleasure / frisson (“chills”)
- **Sources:** Blood & Zatorre (2001), *PNAS* — chills recruit reward/emotion circuitry (ventral striatum, etc.), with autonomic changes. https://www.pnas.org/doi/10.1073/pnas.191355898  
  Salimpoor et al. (2011), *Nature Neuroscience* — dopamine: **caudate ≈ anticipation**, **NAc ≈ peak experience**. https://www.nature.com/articles/nn.2726  
  Ferreri et al. (2019), *PNAS* — dopamine bidirectionally modulates musical pleasure/chills. https://www.pnas.org/doi/10.1073/pnas.1811878116
- **Steal for show:** Pre-chorus / `build` = **anticipation window** (hold, tighten, don’t spend the climax early). Chorus open / first drop hit = **peak window** (one white-out or scale bloom — then ride, don’t restroke). Over-flashing kills contrastive reward.

### 2) Tension / release & expectancy (ITPRA)
- **Source:** Huron (2006), *Sweet Anticipation* (MIT Press) — ITPRA: Imagination, Tension, Prediction, Reaction, Appraisal; pre-outcome tension raises arousal/attention; delayed expected events can heighten later pleasure (contrastive valence). Reviews: Empirical Musicology Review / Pearce-style summaries of Huron.
- **Steal:** Pre section = tension response (push-in, dutch optional, denser hats/snare anticipation). Predicted chorus arrival = prediction reward if world **opens as expected** (same motifs bigger — Formation/Gondry). True surprise (drop gate / harsh) = brief **reaction** (startle flash) then appraisal (readable world returns).

### 3) Entrainment / groove (urge to move)
- **Sources:** Janata, Tomic & Haberman (2012), *JEP:General* — groove as pleasurable sensorimotor coupling. https://doi.org/10.1037/a0024208  
  Witek et al. (2014), *PLOS ONE* — inverted-U: medium syncopation maximizes wanting-to-move + pleasure. https://pmc.ncbi.nlm.nih.gov/articles/PMC3989225/  
  Madison (2006) operational definition of groove (wanting to move with the sound).
- **Steal:** Steady kick/bass pocket → camera pulse / figure sway **entrained**, not random shake. Too-busy spark spam = high complexity side of U (less groove). Medium event density on chorus > constant max.

### 4) Emotion mechanisms (BRECVEMA)
- **Source:** Juslin (2013), *Physics of Life Reviews* — Brain stem reflex, Rhythmic entrainment, Evaluative conditioning, Contagion, Visual imagery, Episodic memory, Musical expectancy, Aesthetic judgment. https://www.sciencedirect.com/science/article/pii/S1571064513000638
- **Steal:** **Brain stem reflex** → rare startle (harsh/drop) only. **Entrainment** → groove pulse. **Visual imagery** → lyric WHAT world (our north star). **Episodic memory** → motif returns / nostalgia color. **Expectancy** → section grammar. Aesthetic judgment → stay directed, not spectrum toy.

### 5) Valence & lyric attention
- **Sources:** Fiveash & Luck (2016), *Psychology of Music* — sad/negative musical valence → more analytic lyric error detection (deeper semantic processing); happy → more heuristic. https://doi.org/10.1177/0305735615628057  
  Juslin & Västfjäll (2008), *Behavioral and Brain Sciences* — need underlying mechanisms for music emotion.  
  Related: lyric+music emotion processing can lag instrumental emotion (ERP timing differences in lyric-present conditions — see Chinese Acad. Psych. ERP work, 2018).
- **Steal:** Dark/sad verse → **hold longer on scenic type + figure** (people read words deeper). Bright chorus → **bigger gesture, fewer words on screen at once** (heuristic mode — huge hook phrase, not dense karaoke). Expire lyric blocks after hold so imagery can breathe.

### 6) Memory / nostalgia
- **Sources:** Juslin BRECVEMA — Episodic memory mechanism.  
  Janata (2009-era autobiographical music memory work; medial prefrontal coupling with familiar songs — cite as Janata, 2009, *Cerebral Cortex* “The neural architecture of music-evoked autobiographical memories” when referencing familiarity/nostalgia).
- **Steal:** Motif callbacks on `chorus.repeat` and outro = memory hits. Familiar palette/figure return heals; constant novelty destroys nostalgia reward.

### 7) Startle vs soothe
- **Sources:** Huron reaction response; Juslin brain-stem reflex; Blood/Zatorre autonomic arousal with chills (not the same as startle — chills = pleasure-linked arousal).
- **Steal:** **Startle** = single gate (thunder/drop/harsh) with immediate restore. **Soothe** = pads fog, silence floors, breakdown float, heal scenery after destruction. Never stack startles; soothe must earn the next peak.

|-----------|-----------|
| Anticipation dopamine (caudate) | **Hold** cut rate in pre; tighten frame; raise `build`; delay white-out |

| Groove / entrainment | Pulse camera/figure with kick pocket; medium density |

| Soothe / breakdown | Pads own frame; expire lyrics; small/distant figure |
