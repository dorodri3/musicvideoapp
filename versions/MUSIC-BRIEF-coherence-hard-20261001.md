## Law
**One fantasy, whole track.** Verse plants the world + cast + motif; chorus / drop = **same movie intensified** (bigger light, closer singer, hotter trim, faster pulse) — never a new genre, new city, or new protagonist mid-song unless lyric+section explicitly chapter-cuts (rare; must return).

## How real MVs hold the thread
1. **Motif memory** — a silhouette, color rim, object, or path returns after every peak (Blinding Lights neon runner; This Is America chapter returns to the FG dancer). After chaos, **re-show** the planted figure/world so the brain stitches continuity.
2. **Chorus intensification ≠ teleport** — scale up: same pack family, same coat wedge, same crosshair; more bloom / formation / kick punch — not meadow→warzone→candy in three phrases.
3. **Section grammar** — intro/verse = plant; pre = tense the same place; chorus = open the same sky; bridge may darken or strip; outro = soothe or dissolve **that** world (psych: anticipation→peak→soothe).
4. **Cast continuity** — one vocalist silhouette for the song; companions may enter/exit but FG identity stays; no outfit roulette every 8 bars.
5. **Earned shifts only** — vibe ladder moves the **intensity of this world**, not a pack lottery. Aggressive peak = storm **in** the planted industrial/street world, not a random red_void wipe with no return.

## Anti-patterns (barely-coherent fail)
- New world every phrase / every lyric line  
- Neon hub forever default fighting the planted fantasy  
- Chorus = different cast archetype  
- Drop = total palette reset with no motif callback  
- Soft verse motifs discarded forever after first chorus
