## 1. Flash Hz / duty (measured)

| Path | Where | Gate today | Peak |
|------|--------|------------|------|
| Renderer kick/snare/drop → `white_flash` | `viz/renderer.js` `_tryWhiteFlash` | `whiteMinGapMs` **280** default; EDM **1200** | `whiteOut = 1` |
| Director `white_flash` | `scenePlan.js` + `variation.canEffect` | **2500** ms | `whiteOut = 1` |
| Director `snare_flash` | same | **280** ms | `whiteOut ≥ 0.45` |
| `kick_punch` | lighting trigger | event-driven | `whiteOut ≥ 0.55` |
| Local `_kickFlash` / `_snareFlash` | renderer draw | decay `*0.84` / `*0.85` | horizon / mid punch (not full white) |

**Decay:** `whiteOut *= 0.82` per update (~60 fps) → visible (`>0.02`) **~300 ms**; half-life **~58 ms**.

**Risk math:** default gap 280 ms ⇒ up to **~3.6 Hz** full white. Visible window ≈ gap ⇒ duty of `whiteOut>0.02` can approach **~100%** when firing at max. Director snare/kick_punch **bypass** the shared `_lastWhiteFlash` timer → stacked near-whites (M3/M4 stand).

### Comfort caps (implement in lighting / `_tryWhiteFlash`)

| Mode | Max full-frame white | Min gap (shared) | Peak `whiteOut` | Notes |
|------|----------------------|------------------|-----------------|-------|
| Artistic default | **≤ 3 Hz** hard | **≥ 500 ms** | 1.0 OK | Raise default `whiteMinGapMs` 280→**500**; keep EDM 1200 |
| Comfort / chaotic-but-watchable | ≤ 2 Hz | **≥ 500–600 ms** | ≤ **0.85** | Cap duty: `whiteOut>0.3` ≤ **~15%** of any rolling 1s |
| `lessFlash` | ≤ 1 Hz | **≥ 1000 ms** | ≤ **0.35** | Mute director/renderer `white_flash`; keep soft snare mid-punch |
| `prefers-reduced-motion` | **0 Hz** full white | — | **0** (mute) | No `white_flash` / `white_out` / `sky_tear` full plate |

**Unify:** one shared last-fire clock for `white_flash` + `kick_punch` + director `snare_flash` when those bump `whiteOut≥0.45`. Local amber horizon / mid radial punches can stay denser.
