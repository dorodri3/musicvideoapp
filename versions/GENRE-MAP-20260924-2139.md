## Family cards

### 1) Pop
- **Arousal / valence:** mid–high / positive  
- **Vibe tags:** peace→hopeful; chorus may lift tense briefly — rarely scary  
- **Worlds:** futuristic_city, dream_clouds, empty_highway dusk, soft rainy_city neon  
- **Cast / dance:** `pop_candy`, `formation_crew` on chorus; freestyle/formation likely  
- **Weapons:** NEVER unless lyric irony  
- **MV steal:** Formation geometry; Blinding Lights neon runner; huge world-lit type on hook  

### 2) Hip-hop / rap
- **Arousal / valence:** mid–high / mixed (boast + dark street)  
- **Vibe tags:** tense, chaos (earned), speechLike on verses  
- **Worlds:** rainy_city, industrial_tunnel, futuristic_city night, empty_highway  
- **Cast / dance:** `fg_performer`, `tableau_figure`; freestyle/body groove; formation on hooks  
- **Weapons:** ONLY lyric/concept gate (This Is America grammar) — never default drip  
- **MV steal:** FG dancer + BG world; long-take chapters; motif callbacks  

### 3) R&B / soul
- **Arousal / valence:** mid / warm–bittersweet  
- **Vibe tags:** peace, tense (quiet storm)  
- **Worlds:** rainy_city night, cathedral_space soft, dream_clouds, ocean dusk  
- **Cast / dance:** `tableau_figure`, intimate freestyle; stillness in ballad verses  
- **Weapons:** NEVER  
- **MV steal:** Close lyric figure; pads aura; scenic type long holds (analytic if sad)  

### 4) Rock / metal / punk
- **Arousal / valence:** high / aggression varies (punk joy-anger; metal darkness)  
- **Vibe tags:** chaos, tense; scary rare (doom)  
- **Worlds:** industrial_tunnel, storm, burning_desert, red_void, ancient_ruins, led_wall  
- **Cast / dance:** `chaos_fracture`, `fg_performer`; headbang/freestyle pulse; formation less common  
- **Weapons:** lyric/war themes only; default none  
- **MV steal:** Kick ground punch as body; harsh ash on chaos cast; earned drop gates  

### 5) Country / folk / americana
- **Arousal / valence:** low–mid / nostalgic ±  
- **Vibe tags:** peace; speechLike on story verses  
- **Worlds:** empty_highway, desert, forest, snow, ancient_ruins soft, ocean  
- **Cast / dance:** `pastoral_walker`, `tableau_figure`; walk > club dance; barn-dance only if joy lyric  
- **Weapons:** NEVER (story guns only if lyric explicit — still brief ash_aftermath preferred)  
- **MV steal:** Highway vanishing point; episodic memory motifs; long lyric holds  

### 6) Jazz / blues
- **Arousal / valence:** mid / bittersweet–cool  
- **Vibe tags:** peace, tense; nonGroove pockets OK  
- **Worlds:** rainy_city, cathedral_space, smoky industrial soft, dream_clouds  
- **Cast / dance:** `tableau_figure`, `spoken_intimate` lean; sway not EDM bounce  
- **Weapons:** NEVER  
- **MV steal:** Pads/sky as horn breath; snare as brush companion gesture; negative space  

### 7) Classical / orchestral / score
- **Arousal / valence:** wide arc (adagio peace → allegro tense)  
- **Vibe tags:** peace, tense, scary (dissonant), rarely speechLike  
- **Worlds:** cathedral_space, space, ocean, snow, endless_staircase, white_void  
- **Cast / dance:** `sacred_solitary`, `cosmic_dissolve`; ritual_gesture; stillness default  
- **Weapons:** NEVER unless programmatic war score + lyric/title gate  
- **MV steal:** Scale lifts with arrangement; motif returns = themes; pads environment agent owns frame  

### 8) Electronic / EDM / ambient / IDM
- **Arousal / valence:** EDM high+/ambient low; IDM tense–curious  
- **Vibe tags:** chaos (big-room peaks), peace (ambient), tense (IDM)  
- **Worlds:** futuristic_city, space, led_wall, dream_clouds, white_void, storm (drops)  
- **Cast / dance:** EDM `neon_runner`/`pop_candy`/formation; ambient fauna/void presence; IDM abstract still+glitch  
- **Weapons:** NEVER  
- **MV steal:** One earned drop bloom (psych); ambient = soothe pads; IDM harsh as texture not war  

### 9) Latin / reggaeton / samba
- **Arousal / valence:** high / positive body  
- **Vibe tags:** peace→joy; groove; rarely scary  
- **Worlds:** futuristic_city warm, ocean, rainy_city carnival light, desert sunset  
- **Cast / dance:** HIGH — freestyle + formation; `pop_candy` / `fg_performer`  
- **Weapons:** NEVER  
- **MV steal:** Entrained kick footfalls; medium syncopation groove U; colorful world-lit type  

### 10) Afrobeat / dancehall / reggae
- **Arousal / valence:** mid–high / warm–resistant  
- **Vibe tags:** peace/groove; tense possible in roots; speechLike toasting  
- **Worlds:** ocean, forest, rainy_city warm, empty_highway dusk, dream_clouds  
- **Cast / dance:** HIGH groove sway / freestyle; formation on hooks  
- **Weapons:** NEVER default; lyric-only  
- **MV steal:** Pocket-first body; hats as spark fauna; no fake EDM white-out spam  

### 11) K-pop / J-pop
- **Arousal / valence:** high / bright (ballad mid/bittersweet)  
- **Vibe tags:** peace/hope; tense in pre-chorus  
- **Worlds:** futuristic_city, dream_clouds, white_void candy, led_wall, space soft  
- **Cast / dance:** VERY HIGH — `formation_crew` precision; `pop_candy`  
- **Weapons:** NEVER  
- **MV steal:** Formation geometry max; motif color accents; chorus huge type; clean harsh≈0  

### 12) Gospel / worship
- **Arousal / valence:** mid–high / hope+  
- **Vibe tags:** peace; awe  
- **Worlds:** cathedral_space, dream_clouds, space, white_void soft light, ocean  
- **Cast / dance:** `sacred_solitary` → `formation_crew` choir geometry; ritual_gesture; joy sway  
- **Weapons:** NEVER  
- **MV steal:** Shaft light; pads aura; scale to cosmic on lift; heal not destroy  

### 13) Indie / alt
- **Arousal / valence:** mid / bittersweet–detached  
- **Vibe tags:** peace, tense; occasional chaos  
- **Worlds:** rainy_city, empty_highway, forest, ancient_ruins, dream_clouds, snow  
- **Cast / dance:** `tableau_figure`, `pastoral_walker`; still/walk > formation  
- **Weapons:** NEVER default  
- **MV steal:** Negative space; motif returns; scenic type; underplay kick in verses  

### 14) Soundtrack / trailer-cue
- **Arousal / valence:** designed arcs (build→hit)  
- **Vibe tags:** tense→chaos or peace→awe by cue  
- **Worlds:** match narrative fantasy (any pack) — score logic  
- **Cast / dance:** cinematic `tableau_figure` / `cosmic_dissolve`; dance rare unless diegetic  
- **Weapons:** only if cue/lyric world is war (gated)  
- **MV steal:** Huron anticipation; one hit; motif like leitmotif  

### 15) Spoken-word / non-groove
- **Arousal / valence:** low–mid / content-driven  
- **Vibe tags:** spoken, speechLike, nonGroove, peace or scary by words  
- **Worlds:** soft void, forest, ocean, intimate rainy_city room  
- **Cast / dance:** `spoken_intimate`; stillness — micro-gesture only  
- **Weapons:** NEVER unless text explicitly stages them  
- **MV steal:** Lyric-as-world; minimal punch; silence→ambient (VIBE spoken mode)  

### 16) Experimental / noise
- **Arousal / valence:** unstable / often negative–curious  
- **Vibe tags:** chaos, scary, tense; nonGroove  
- **Worlds:** red_void, white_void, industrial_tunnel, reality_fracture/storm, endless_staircase  
- **Cast / dance:** `void_presence`, `chaos_fracture`; anti-dance / glitch body; stillness OK  
- **Weapons:** abstract only if lyric; prefer harsh ash over gun glyphs  
- **MV steal:** harsh role-agent; rare startle; no pop candy; don’t fake chorus

## Soft detect hints (Audio)
- High kick+bass periodic + high hats → electronic/latin/afrobeats lean  
- High vocalish + weak kick pocket → spoken / intimate R&B ballad  
- High harsh + flux → metal/punk/noise  
- High pads + low kick → ambient/classical adagio / worship pad  
- Mid shuffle + warm → jazz/blues/reggae lean
