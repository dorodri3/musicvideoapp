## Ranked risks

### P0 — likely tanks phone FPS

1. **Full-viewport multi-pass fill** — clear + lighting washes/bloom radials + fog/vignette + LED + typography every frame (`renderer.js`, `lighting/system.js`). Cap DPR (1.5 / 1 low-end); skip bloom layer 2 + LED at low q; cache vignette/bloom gradients when size stable.

2. **Continuity morph = draw scene twice + offscreen** — `continuity.js` ~1.8s morph doubles preset cost; buffer recreates on resize. Morph only at q≥0.85; else hard cut / single alpha wipe.

3. **`semantic.extract()` full corpus every rAF** — `main.js` → `lyrics/semantic.js`. Cache at plan / lyrics change; keep `extractLine` on phrase change only.

4. **Analyzer FFT 2048 + per-frame alloc** — `audio/analyzer.js`: new `roles`/`frame`, **`Object.defineProperty` every frame**, `shift`/`slice` histories. FFT 1024 on phone; mutate reused bags; ring buffers; plain `vocalish` field.

5. **`atmosParticles` uncapped by quality** — `presets.js` 20–60 path ops; intensity can exceed 1. Multiply by quality/`particleMul`; hard cap ~24 on phone.

6. **Typography heavy `shadowBlur` (18–60) + repeated `measureText`** — `typography/system.js`. Soft blur is a Canvas2D phone killer. Glow only at high q; cache line metrics; solid scrim at low q.

### P1 — jank / battery

7. Per-frame `_resize` + quality canvas rewrite hitches.  
8. Lighting: 2 bloom radials + LED grid (~10×6) often always on; wire `bloomMul`.  
9. Hat needles 14–62×q, glitch ash 24×q — cap needles, skip ash below q0.7.  
10. Dense presets: space stars 120–200, ocean ~4×(w/6) lineTos, led_wall up to 112 cells, rainy/futuristic window grids. Scale by quality; cache star field.  
11. Motif `shadowBlur` up to 30.  
12. Director/emotion/camera/vocal new objects every frame → GC. Reuse bags.  
13. Camera/ground shake `Math.random` every shake frame.

### P2

14. Hex parse / rgba strings per bloom fill.  
15. HUD DOM updates near `% 500` boundary can multi-fire.  
16. Minor: intro theme measure uncached; continuity bridge path mid-morph.

## Recommended fix order (ideas only — locked)

1. Cache `semantic.extract` (stop per-frame).  
2. Reuse analyzer frame/roles; FFT 1024; kill per-frame `defineProperty`.  
3. Cap DPR; resize on observer only; apply quality + caps to atmos/stars/ocean/LED cells.  
4. One bloom radial + optional LED; honor `bloomMul`.  
5. Soften/remove typography `shadowBlur` on low quality.  
6. Avoid double-preset morph under load.  
7. Wire `particleMul`; add `prefers-reduced-motion` (fewer particles / no shake / no morph).
